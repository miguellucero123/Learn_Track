# 🚀 LearnTrack Dashboard
**Sistema Predictivo de Retención Estudiantil con Inteligencia Artificial**

![Status](https://img.shields.io/badge/Status-Beta_Funcional-success)
![Tech](https://img.shields.io/badge/Tech-HTML5_JS_Bootstrap-blue)
![AI Model](https://img.shields.io/badge/AI-Logistic_Regression-orange)

LearnTrack es una plataforma web diseñada para instituciones educativas que utiliza **Machine Learning** para identificar tempranamente a estudiantes en riesgo de deserción, permitiendo intervenciones oportunas y basadas en datos.

---

## 🌟 Características Principales

### 1. 📊 Dashboard de Alto Impacto
- Visualización en tiempo real de KPIs críticos.
- Gráficos interactivos (Chart.js) de tendencias y distribución de riesgo.
- **Modo Ejecutivo:** Resumen de métricas financieras ($ Recuperado).

### 2. 🔐 Seguridad y Acceso
- Sistema de **Login seguro** (Simulado).
- Protección de rutas (Redirección automática si no hay sesión).
- Credenciales Demo: `admin` / `admin`.

### 3. 🔮 Simulador Predictivo "What-If" (AI Core)
- **Motor de Regresión Logística:** Calcula probabilidades reales usando función Sigmoide.
- Permite simular escenarios: *"¿Cuánto baja el riesgo si mejora la asistencia un 10%?"*.
- Visualización inmediata del impacto de las intervenciones.

### 4. 📄 Reportabilidad Automática
- Generación de **Informes PDF** profesionales con un clic.
- Incluye tablas de riesgo, gráficos y recomendaciones automáticas.

---

## 🛠️ Tecnologías Utilizadas

*   **Frontend:** HTML5, CSS3 (Bootstrap 4), JavaScript (Vanilla ES6+).
*   **Visualización:** Chart.js (Gráficos), FontAwesome (Iconos).
*   **Motor AI:** Lógica de Regresión Logística implementada en JS puro.
*   **Utilidades:** jsPDF (Reportes), LocalStorage (Persistencia de datos).

## 🚀 Instalación y Uso

### Opción A: Ver Online (Recomendado)
Accede a la versión desplegada en GitHub Pages:
👉 **[https://miguellucero123.github.io/Learn_Track/](https://miguellucero123.github.io/Learn_Track/)**

### Opción B: Ejecutar Localmente
1.  Clona el repositorio:
    ```bash
    git clone https://github.com/miguellucero123/Learn_Track.git
    ```
2.  Navega a la carpeta:
    ```bash
    cd Learn_Track
    ```
3.  Abre el archivo `index.html` en tu navegador favorito.
    *   *Nota: Para una mejor experiencia, usa un servidor local como "Live Server" en VS Code.*

---

## 📖 Guía de Uso Rápida

1.  **Inicio:** Haz clic en **"Abrir Aplicación"**.
2.  **Login:** Ingresa `admin` / `admin`.
3.  **Explora:**
    *   Revisa los KPIs superiores.
    *   Filtra la tabla por carrera.
4.  **Simula:** Haz clic en el **Ojo (👁️)** de un estudiante y luego en **"Simular Escenarios"**. Mueve los sliders y observa la IA en acción.
5.  **Exporta:** Presiona **"Exportar"** para descargar el reporte PDF oficial.
